Casa Domòtica Intel·ligent

Projecte d'automatització d'una llar: inclou un timbre interactiu, il·luminació activada per so i un sistema de control de climatització i qualitat de l'aire.

Objectius

  • Entendre els conceptes bàsics de la domòtica i l'automatització.
  • Programar diferents subsistemes: timbre, llum per so i control climàtic.
  • Crear subrutines (funcions) per gestionar cada habitació o sistema de la casa.

Materials Necessaris

  • Placa amb microcontrolador (ESP32 / Arduino)
  • Sensor de Temp. i Humitat (DHT-11)
  • Sensor de CO2/TVOC (CCS811)
  • Sensor de So (Analògic)
  • 3 x LEDs (Llums de la casa) i 1 x Pulsador
  • Brunzidor (Buzzer per al timbre)

1. Descripció del Repte

El repte consisteix en dissenyar i programar el cervell d'una Casa Domòtica. Aquesta casa intel·ligent tindrà tres funcions principals: un timbre a la porta que farà sonar una melodia quan hi hagi visites, un llum automàtic que s'encendrà en detectar un soroll fort (com una picada de mans), i un sistema de control de climatització que ens avisarà si la temperatura, la humitat o els nivells de CO2 de les habitacions no són òptims per al nostre confort.

2. Muntatge i Connexions

Connecta els diferents mòduls de la casa als següents pins de la placa:

• Pin 2: LED d'Alerta (Aire viciat o temperatura extrema)
• Pin 3: LED de Confort (Clima i aire correctes)
• Pin 4: Sensor DHT-11 (Monitoratge de Temp i Humitat a dins de casa)
• Pin 6: Pulsador (El botó del timbre de la porta)
• Pin 7: LED d'Il·luminació (S'encén amb el soroll)
• Pins 12 i 13: Brunzidors (Altaveus del timbre)
• Pin A1: Sensor de So (Detector de sorolls/picades de mans)
• Pins I2C: Sensor de CO2 CCS811

3. Programació amb STEAMakersBlocks

El cervell de la casa té un Bucle principal que s'executa contínuament i s'encarrega de cridar a les subrutines (funcions) que gestionen de forma independent cada espai de la llar.

Explicació pas a pas de les Funcions

1. Funció TOCA PULSador (El Timbre de la Porta)

Aquesta funció controla la porta d'entrada. Si es prem el polsador del Pin 6, es fa sonar el timbre generant dues notes musicals consecutives.

Representació del codi:

FUNCIONS definir TOCA PULSador
LOGICA si Pin [6] premut
BRUNZIDOR pin [ 12 ] [ SOL ] [ 500 ms ]
BRUNZIDOR pin [ 13 ] [ DO ] [ 1000 ms ]

2. Funció SO2 (Il·luminació Automàtica)

Llegeix el sensor de so (Pin A1) per detectar picades de mans. Envia el valor al port sèrie i, si se supera el llindar establert, encén el llum LED del Pin 7 de forma automàtica durant 3 segons (3000 ms).

Representació del codi:

FUNCIONS definir SO2
VARIABLES valor soroll = Pin analògic [ A1 ]
LÒGICA si valor soroll > llindar
Escriure pin digital [ 7 ] [ ALT ]
Esperar [ 3000 ms ]
Escriure pin digital [ 7 ] [ BAIX ]

3. Funció TEMP (Climatització i Confort)

Aquesta funció actua com a termòstat i analitzador de salut, avaluant alhora els llindars de Temperatura (15-25ºC), Humitat (40-65%) i nivells de CO2 (máxim 1000ppm).

Representació del codi:

FUNCIONS definir TEMP
LÒGICA si ( Fora de rang )
Escriure Pin [ 2 ] (LED Alerta) [ ALT ]
sino
Escriure Pin [ 3 ] (LED Confort) [ ALT ]

4. Ampliació i Reptes

Suggereix als alumnes modificacions per seguir millorant aquesta llar intel·ligent:

  • Afegeix un servomotor a la porta perquè s'obri automàticament en posar una contrasenya.
  • Utilitza un sensor de llum (LDR) perquè els llums només s'encenguin amb el soroll si és de nit.
  • Investiga com connectar la casa al WiFi per enviar alertes de temperatura al teu telèfon.
